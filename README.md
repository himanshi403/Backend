A responsive thrift shopping website built using **HTML, CSS, and JavaScript**. The project offers a clean and user-friendly interface for browsing second-hand fashion products while promoting sustainable shopping.

## Features
- Responsive design
- Product listings
- Shopping cart UI
- Modern and clean interface

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Run Locally
1. Clone the repository.
2. Open `index.html` in your browser.
